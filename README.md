# ScaleUp Digital

Website for ScaleUp Digital, showcasing virtual assistance, social media management, and digital marketing services.

## Project files

- `index.html` — Main website, service packages, and contact form.
- `styles.css` — Layout, responsive styling, and visual theme.
- `script.js` — Navigation, package selection, Kenya time display, form handling, and scroll effects.
- `privacy-policy.html` — Privacy policy page.
- `photos/` — Logo and website imagery.
- `robots.txt` and `sitemap.xml` — Search engine crawling and sitemap files.

## Run locally

No build step or package installation is required. Open `index.html` in a browser, or serve the project directory with a local static web server.

The site loads fonts from Google Fonts and submits its contact form through Formspree, so those features require an internet connection.

## Contact form

The form is configured to submit to Formspree from `index.html`. Confirm that the endpoint is connected to the intended Formspree account and inbox before publishing.
